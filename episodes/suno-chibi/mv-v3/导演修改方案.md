# 赤壁借风 · v3 导演修改方案

审片对象：`episodes/suno-chibi/赤壁借风-周瑜对诸葛亮-成片-v2.mp4`（42.33 秒，13 镜）。
审片方式：整片每 1/3 秒抽帧逐格看，加上镜头切点检测和原歌节拍分析。帧图在 `_review/`。
**口型准不准没法靠抽帧判断，验收时必须在播放器里放出声音看。**

## 一句话结论

v2 不精彩，问题不在模型参数，而在**参考图和剪辑结构**：5 张参考图全是平视中近景、几乎同一机轴，Ref2VA 又会锁住参考图构图，所以 13 个镜头看起来像同一个镜头；三个镜头共用一张观众图（合计 13.8 秒，其中约 11 秒构图几乎一样）；诸葛亮唱的时候周瑜一次也没出现；歌词里能演的梗都没演。
v3 不改歌、不改词、不改参数，只做三件事：**补 11 张不同机位的参考图、把剪辑改成 19 个切点并踩小节线、每句歌词配一个看得懂的动作**。

## v3 结构

19 个剪辑点，平均 2.2 秒一个（v2 是 3.3 秒）。叙事线：

1. **周瑜回合**：开麦热场 → 仰拍自夸 → 学人摇扇（切诸葛亮挑眉）→ 过肩横移 → 贴脸挑衅
2. **回合交接（间奏）**：诸葛亮不接招的对视 → 两人绕场 → 羽扇特写 → 周瑜勾手 "来啊" → 诸葛亮仰拍接麦 "Yeah"
3. **诸葛亮回合**：一扇子把周瑜吹得后仰 → 踱步敲太阳穴（切周瑜咬牙）→ 对镜头扇尖直指 → 推到大特写斜眼
4. **落点**：周瑜想回嘴、愣住、苦笑认输 → 台上反打全场欢呼，诸葛亮像冠军 → 升高拉远

规则执行：唱的人站画左（周瑜回合周瑜在左，诸葛亮回合换轴）；独立观众镜头只有 C18、C19 两次，而且台上都有人；麦克风一律右手、低于嘴；羽扇左手、唱歌时不过嘴；反应镜头一律**静音驱动**，防止听的人跟着对方的歌词动嘴。
